# Швидкий старт

## 1. Встановлення

```bash
cd website
npm install
```

## 2. Налаштування

Створіть файл `.env.local`:

```bash
cp .env.example .env.local
```

Відредагуйте `.env.local` та додайте ваші дані EmailJS та контакти.

## 3. Запуск

```bash
npm run dev
```

Відкрийте браузер: http://localhost:3000

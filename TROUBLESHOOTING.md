# Решение проблем

## Ошибка: Failed to read source code from lib/i18n.ts

Если вы видите эту ошибку после рефакторинга переводов:

1. **Очистите кеш Next.js:**
   ```bash
   rm -rf .next
   rm -rf node_modules/.cache
   ```

2. **Перезапустите dev сервер:**
   ```bash
   npm run dev
   ```

3. **Если проблема сохраняется, проверьте:**
   - Убедитесь что файл `lib/i18n/index.ts` существует
   - Проверьте что все импорты используют `@/lib/i18n` (без расширения .ts)
   - Убедитесь что в `tsconfig.json` правильно настроен path alias `@/*`

4. **Если все еще не работает:**
   - Перезапустите TypeScript сервер в IDE
   - Удалите `node_modules` и переустановите: `rm -rf node_modules && npm install`

## Структура переводов

Переводы теперь находятся в отдельных файлах:
- `lib/i18n/uk.ts` - Украинский
- `lib/i18n/en.ts` - Английский
- `lib/i18n/de.ts` - Немецкий
- `lib/i18n/fr.ts` - Французский
- `lib/i18n/pl.ts` - Польский
- `lib/i18n/sv.ts` - Шведский
- `lib/i18n/index.ts` - Главный файл экспорта

Все импорты должны использовать: `import { ... } from "@/lib/i18n"`
